# API Reference (summary)

Full interactive docs (request/response schemas, try-it-out) are auto-generated by FastAPI at
**`/docs`** (Swagger UI) and **`/redoc`** once the backend is running. This file is a quick-scan
supplement for reviewers who don't want to spin up the server.

Base URL (local): `http://localhost:8000`

All protected routes require `Authorization: Bearer <session JWT>` (issued by `/api/auth/google`,
not Google's own token).

## Auth

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/auth/google` | none | Body: `{ id_token }` (Google ID token from the frontend). Verifies it against Google's public keys, creates or logs in the user, returns `{ access_token, user }`. |
| `GET` | `/api/auth/me` | customer/admin | Returns the current user's profile. |

## Products

| Method | Path | Auth | Description |
|---|---|---|---|
| `GET` | `/api/products` | none | List active products. |
| `GET` | `/api/products/{id}` | none | Single active product. |
| `GET` | `/api/admin/products` | admin | List **all** products, including deactivated ones. |
| `POST` | `/api/admin/products` | admin | Create a product. |
| `PUT` | `/api/admin/products/{id}` | admin | Partial update (any subset of fields). |
| `DELETE` | `/api/admin/products/{id}` | admin | Soft-delete (`is_active = false`). |

## Orders

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/orders/checkout` | customer/admin | Body: `{ items: [{ product_id, quantity }] }`. Validates stock, reserves it, creates the order, opens a Stripe Checkout Session, returns `{ order_id, checkout_url }`. |
| `GET` | `/api/orders` | customer/admin | The current user's own orders. |
| `GET` | `/api/orders/{id}` | customer/admin | A single order — 403 if it belongs to a different customer (admins can view any). |
| `GET` | `/api/admin/orders` | admin | All orders, across all customers. |

## Payments

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/webhooks/stripe` | Stripe signature (`Stripe-Signature` header, verified with `STRIPE_WEBHOOK_SECRET`) | Handles `checkout.session.completed` (→ order `paid`) and `checkout.session.expired` / `checkout.session.async_payment_failed` (→ order `failed`, stock restored). |

## AI support agent

| Method | Path | Auth | Description |
|---|---|---|---|
| `POST` | `/api/ai/chat` | customer/admin | Body: `{ message }`. Runs a LangGraph agent (Gemini) with tools scoped to the caller's own data; returns `{ reply }`. |

## Misc

| Method | Path | Auth | Description |
|---|---|---|---|
| `GET` | `/api/health` | none | Liveness check. |

## Error shape

FastAPI's default HTTPException format: `{ "detail": "<message>" }`, with the appropriate status
code (`400`, `401`, `403`, `404`, `502`).
